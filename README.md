## 🛒 購物明細功能

- **商品選取**：從常備商品庫選取，支援多品項
- **贈品選取**：從贈品庫選取，自動標記【贈品】，不計入金額
- **計算公式**：`(商品原價 × 數量) − 扣抵點數 − 扣抵優惠券 + 運費 = 實收`
- **運費快速鍵**：免運 $0 ／ 🚚 宅配 ／ 🏪 超商（自填金額）
- **歷史記錄**：各欄位記憶上次輸入值，可點選填入或刪除

## 💾 資料儲存

所有資料存於瀏覽器 `localStorage`（不上傳任何伺服器）：

| Key | 內容 |
|-----|------|
| `ecoco_i_v6` | 發票申請資料 |
| `ecoco_p_v6` | 常備商品清單 |
| `ecoco_g_v6` | 常備贈品清單 |
| `ecoco_pw_overrides` | 密碼覆寫（忘記密碼用） |
| `ecoco_calc_history` | 計算欄位歷史記錄 |

---

## 🧹 清除測試資料

在瀏覽器開發者工具（F12 → Console）貼上：

```javascript
// 清除所有發票資料（保留商品庫）
localStorage.removeItem('ecoco_i_v6');
location.reload();

// 完全重置（清除所有資料）
['ecoco_i_v6','ecoco_p_v6','ecoco_g_v6','ecoco_pw_overrides','ecoco_calc_history']
  .forEach(k => localStorage.removeItem(k));
location.reload();
```
